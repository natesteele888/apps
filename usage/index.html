Hook up GitHub

This shows your GitHub Actions minutes. It needs a read-only key from GitHub. It stays on this phone and is only ever sent to GitHub.

  1. On GitHub, open Settings › Developer settings › Fine-grained tokens › Generate new token.
  2. Name it Usage. Expiration: 1 year.
  3. Under Permissions, open Account, find Plan and set it to Read-only. Nothing else.
  4. Tap Generate token, copy it, paste it below.
