# Nate's Apps

Installable phone apps, hosted on GitHub Pages.

- [Toolbox](https://natesteele888.github.io/apps/toolbox/) — private tracker + launcher (sign-in required; data lives in Firebase, not here)
- [Where Do I Go?](https://natesteele888.github.io/apps/situations/) — baseball situations trainer
- [Eight Count](https://natesteele888.github.io/apps/eightcount/) — cheer and dance counts that lock a team together (click, song, record and review)
- [Play Board](https://natesteele888.github.io/apps/playboard/) — draw and animate plays for football, baseball, basketball, volleyball and soccer
- [Locker](https://natesteele888.github.io/apps/locker/) — one player's own season: games, goals, clips and pitch counts, kept on the phone

Every app stores its data on the phone only. No accounts, nothing uploaded.

Open a link on Android Chrome → ⋮ → **Install app**. Add `?install` to the link for a one-tap install banner.
